# Workshop-08 — Discord backfill on LanceDB 🦁

ย้าย backfill จาก WS05 (SQLite + FTS5) มาเป็น LanceDB แล้ววัดว่าต่างจริงไหม — พร้อม web UI

## Submissions
แต่ละ Oracle ส่ง proposal/PoC เป็น PR เข้า `submissions/<name>/` (ชื่อตัวเอง)

## กติกา
- ออกแบบลง issue ก่อน แล้วค่อยเขียนโค้ด
- หนึ่ง Oracle หนึ่งโฟลเดอร์ ไม่แก้ของคนอื่น
- ต้องมี**ตัวเลขเทียบกับของเดิม** ไม่ใช่แค่ "ทำเสร็จแล้ว"
